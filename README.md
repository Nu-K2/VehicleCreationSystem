# README

## Практическая работа №2: Реализация порождающего паттерна «Абстрактная фабрика» в C#

---

## Описание проекта

Консольное приложение **«Система создания транспортных средств»** на языке C#, демонстрирующее работу порождающего паттерна проектирования **«Абстрактная фабрика» (Abstract Factory)**.

Программа позволяет пользователю создавать семейства связанных объектов (автомобили и мотоциклы) разных типов двигателей (электрические и бензиновые), управлять ими и выполнять специфические для каждого типа действия.

---

## Цель работы

Закрепить теоретические знания по теме «Назначение и виды паттернов» и получить практические навыки реализации паттерна «Абстрактная фабрика» в консольном приложении на C#.

---

## Архитектура

### Интерфейсы транспортных средств

| Интерфейс | Методы | Назначение |
|-----------|--------|------------|
| `IVehicle` | `Start()`, `Stop()`, `GetInfo()`, `Id` | Базовый интерфейс для всех ТС |
| `ICar` | `OpenTrunk()`, `CloseTrunk()` | Дополнительные методы автомобиля |
| `IMotocycle` | `DoWheelie()` | Дополнительный метод мотоцикла |

### Иерархия классов

```
IVehicle
├── Vehicle (abstract)
│   ├── Car (abstract) : ICar
│   │   ├── ElectricCar
│   │   └── GasCar
│   └── Motocycle (abstract) : IMotocycle
│       ├── ElecticMotocycle
│       └── GasMotocycle
```

### Фабрики

| Фабрика | Создаёт |
|---------|---------|
| `ElectricVehicleFactory` | `ElectricCar`, `ElecticMotocycle` |
| `GasVehicleFactory` | `GasCar`, `GasMotocycle` |

## Функциональность

### Главное меню

| Пункт | Действие |
|-------|----------|
| 1 | Создать автомобиль (с выбором типа двигателя) |
| 2 | Создать мотоцикл (с выбором типа двигателя) |
| 3 | Показать все транспортные средства |
| 4 | Запустить все транспортные средства |
| 5 | Остановить все транспортные средства |
| 6 | Очистить список |
| 7 | Действия с конкретным ТС (по ID) |
| 8 | Выход из программы |

### Действия с конкретным транспортным средством (пункт 7)

**Для автомобиля:**
- Запустить
- Остановить
- Открыть багажник
- Закрыть багажник

**Для мотоцикла:**
- Запустить
- Остановить
- Выполнить трюк (Wheelie)

## Особенности реализации

### Бизнес-логика (`VehicleManager`)

- Хранит список созданных ТС (`List<IVehicle>`)
- `CreateVehicle(string type, IVehicleFactory factory)` — создание ТС через фабрику
- `ShowAllVehicles()` — вывод информации обо всех ТС
- `StartAllVehicles()` / `StopAllVehicles()` — групповое управление
- `ClearAllVehicles()` — очистка списка
- `FindVechicle(int id)` — поиск ТС по ID

### Логика состояний

- **Автомобиль нельзя запустить**, если открыт багажник
- **Багажник нельзя открыть**, если автомобиль движется
- **Трюк нельзя выполнить**, если мотоцикл стоит
- Повторный запуск/остановка выводят соответствующее уведомление

### Автоматическая идентификация

Каждому транспортному средству при создании присваивается уникальный `Id` (статический счётчик `_nextId`).
